# cobanih

Aplikasi **Perpustakaan Sekolah Digital** — pengembangan aplikasi peminjaman buku
berbasis web (Uji Kompetensi RPL).

Kode aplikasi lengkap berada di folder [`perpustakaan-sekolah/`](perpustakaan-sekolah/).
Lihat [`perpustakaan-sekolah/README.md`](perpustakaan-sekolah/README.md) untuk
panduan menjalankan & deploy, serta folder [`perpustakaan-sekolah/docs/`](perpustakaan-sekolah/docs/)
untuk dokumentasi (ERD, deskripsi program, dokumentasi fungsi, catatan debugging,
laporan evaluasi).
